# UI Guide — Гусь и Огурчик

## 1. Концепция

Приложение предназначено для хостес и администраторов ресторана.

Основное устройство:
- iPad (горизонтальная ориентация)

Главный принцип:
- максимум информации
- минимум кликов
- спокойный интерфейс
- ощущение премиального ресторана

---

## 2. Вдохновение

Интерьер ресторана:
- теплый свет
- дерево
- арки
- латунь
- темно-зеленые элементы

Интерфейс должен выглядеть продолжением ресторана, а не обычной CRM.
